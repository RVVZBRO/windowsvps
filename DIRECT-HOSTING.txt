VZ — QUICK START

HOST A PLACE
1. Open VZ.exe.
2. Select your local .rbxl or .rbxlx file.
3. Click HOST SESSION.
4. VZ starts the selected place as a Studio test server.
5. VZ opens a separate Studio player client for you.
6. VZ asks Windows to allow inbound UDP 55556 (one-time administrator approval).
7. VZ requests a one-hour router port mapping and renews it while hosting.
8. Copy the VZ5_ invite and share it with friends.
9. Keep VZ and Roblox Studio running.

JOIN A PLACE
1. Open VZ.exe.
2. Open JOIN SESSION.
3. Paste the host's VZ5_ invite.
4. Click JOIN SESSION.
5. VZ checks the host gateway and opens a Studio player client.

WHAT PLAYERS NEED
- VZ Windows application.
- A compatible Roblox Studio installation.
- A VZ5_ invite from the host.

NETWORK MODES
- Internet: router UPnP IGD enabled + public IPv4 from ISP.
- Same LAN: VZ offers a LAN invite if a public router mapping cannot be made.
- CGNAT / restrictive NAT: direct internet hosting will not work. You need a
  public relay or third-party tunnel service. VZ does not create public cloud
  infrastructure or invent free VM capacity.

SAFETY
- VZ adds one specific inbound UDP 55556 firewall rule after Windows asks.
- The router mapping expires after one hour if VZ crashes; VZ renews it every
  20 minutes during active hosting and removes it on a normal Stop.
- The invite contains the endpoint and session key. Only share it with people
  you trust. Public IPs are visible to invite recipients.
- The selected map is not uploaded or published to Roblox.

COMPATIBILITY
This uses Roblox Studio's unpublished StartServer/StartClient test pathway,
not official Roblox Player matchmaking. Studio's internal startup flags and
network protocol can change. A compiled application has not yet been proven
to connect two real PCs across two networks.
