VZ — QUICK START

HOST A PLACE
1. Open VZ.exe.
2. Select your local .rbxl or .rbxlx file.
3. Click HOST SESSION.
4. Copy the VZ4_ invite and send it to friends.
5. Keep VZ and Roblox Studio running.

JOIN A PLACE
1. Open VZ.exe.
2. Open JOIN SESSION.
3. Paste the host's VZ4_ invite.
4. Click JOIN SESSION.

WHAT PLAYERS NEED
- VZ Windows application.
- Compatible Roblox Studio installed locally.
- A host invite from the person running the session.

Players do not need a VPS account, Porthole, a map copy, UPnP, or router
port-forwarding. The project owner operates one shared VZ UDP relay.

OWNER — ONE-TIME RELAY SETUP
Read deploy/oracle/README.txt. The shared relay runs on one Oracle Cloud
Always Free VM. The first deployment requires the owner to create the Oracle
account/VM and set the VM's public IPv4 in relay/endpoint.txt.

COMPATIBILITY
VZ launches Roblox Studio's unpublished StartServer/StartClient test flow.
This is experimental and is not official Roblox Player matchmaking. Both
computers need a compatible Studio version. VZ does not upload or publish
the selected local place.
